# Blue Dental — 7 Page Starter

قالب اولیه و قابل توسعه وب‌سایت دندانپزشکی با HTML/CSS/JS.

## صفحات
- index.html — خانه
- about.html — درباره ما
- services.html — خدمات
- treatments.html — تخصص‌ها
- technology.html — تکنولوژی
- blog.html — مجله
- contact.html — تماس و نوبت

## ساختار
- css/style.css — طراحی ریسپانسیو و شیشه‌ای
- js/main.js — مگامنو موبایل، reveal on scroll، شمارنده و parallax/scale تصاویر
- images/ — تصاویر SVG جایگزین و favicon

## نکته
تمام متن‌ها و تصاویر محتوای نمونه‌اند و برای جایگذاری محتوای واقعی آماده شده‌اند. فرم نوبت‌دهی در این نسخه نمایشی است و برای ارسال واقعی باید به سرویس فرم، ایمیل یا API متصل شود.
